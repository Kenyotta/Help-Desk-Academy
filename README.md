\# 🎧 Help Desk Academy



A hands-on IT Support portfolio built using the \*\*ServiceDesk Simulator Pro\*\* platform. This repository documents realistic Tier 1 help desk incidents, showcasing my troubleshooting process, customer communication, and adherence to standard operating procedures (SOPs).



Unlike traditional labs that focus only on technical configuration, this project emphasizes the complete support lifecycle—from receiving a ticket to documenting the resolution.



\---



\## 🎯 Project Objectives



\- Develop real-world Tier 1 Help Desk troubleshooting skills.

\- Practice professional customer communication through chat and phone calls.

\- Learn to investigate incidents using evidence rather than assumptions.

\- Follow documented SOPs to resolve issues efficiently.

\- Build a portfolio of completed service desk incidents for interviews and career growth.

\## 🧠 My Troubleshooting Methodology



Every ticket follows the same structured investigation process:



1\. Read and assess the incident.

2\. Determine business impact and priority.

3\. Develop initial hypotheses.

4\. Gather evidence using available tools.

5\. Interview the user and ask clarifying questions.

6\. Test hypotheses and identify the root cause.

7\. Resolve the issue following company SOPs.

8\. Verify functionality with the user.

9\. Document the incident and lessons learned.



\---



\## 📚 Learning Philosophy



The goal of this project is not simply to resolve tickets.



Each investigation focuses on understanding:



\- \*\*Why\*\* the issue occurred.

\- \*\*How\*\* it was diagnosed.

\- \*\*Why\*\* a particular resolution was chosen.

\- \*\*When\*\* escalation is appropriate.

\- \*\*How\*\* to communicate effectively with end users throughout the support process.
